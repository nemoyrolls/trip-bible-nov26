# Road Atlas, November

A trip bible for a 6-day camper van trip in November 2026: Delft → Frankfurt → Bolzano → Venice → Verona → Partnachklamm → highline179 → Ulm → Marburg. It's a static site with no build step.

- `js/trip.js`: every fact (times, prices, sources). Edit here.
- `js/photos.js`: photo credits (generated by `tools/photos_build.py` from Wikimedia Commons).
- `data/`: OSRM route geometry and the elevation profile (`tools/route.py`, `tools/elevation.py`).
- Live data with no keys: Open-Meteo (weather), E-Control (Austrian diesel prices).
- `sw.js`: offline support.
